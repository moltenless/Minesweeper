# 💣 Classic Minesweeper (Screenshots are below)

**Relive the timeless puzzle game of logic and luck — uncover the grid, avoid hidden bombs, and use clever deduction to win! Application with customizable bombs and hint support.**

---

## 🎮 Gameplay Overview

- 🧱 **Reveal Cells**: Click to uncover cells — numbers show how many bombs are adjacent.
- 🚩 **Flag Bombs**: Right-click to mark a cell as a suspected bomb.
- 🧠 **Use Logic**: Use the numbers and flags to deduce where the bombs are.
- 💡 **Get a Hint**: Stuck? Use the tip button to safely reveal a cell.
- ⚙️ **Customize Difficulty**: Set your own bomb count for a tailored challenge.
- 🕹️ **Responsive Grid** – Auto-reveal of nearby empty cells for fast play.
